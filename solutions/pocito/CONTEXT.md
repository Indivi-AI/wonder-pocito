# Wonder Platform

Wonder Platform lets a room curate reusable capabilities and organizational knowledge, then connect them to agents.

## Language

**Knowledge Base**:
A room-owned, reusable collection of Knowledge Content that can be connected to multiple agents. An agent can connect to multiple Knowledge Bases.
_Avoid_: Knowledge, knowledges, document collection

**Knowledge Content**:
A user-provided file or text source contained in a Knowledge Base.
_Avoid_: Knowledge Document, asset, attachment

**Knowledge Connection**:
The relationship that makes a Knowledge Base available to an agent.
_Avoid_: Upload, embedding
